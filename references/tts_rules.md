# 物理配音口语化规范（TTS Guardrails）

编写 `narration.json` 讲稿或运行 `build_audio.py` 时，必须把书面公式与易错多音字转成自然口语：

## 1. 物理量与角标读法
- `v₀` / `v_0` → `初速度 v 零`
- `vₜ` / `v_t` → `末速度 v t`
- `Δx` / `Δv` / `ΔΦ` → `位移变化量 delta x` / `速度变化量 delta v` / `磁通量变化量 delta phi`
- `μ` → `动摩擦因数 miu`
- `ω` → `角速度 omega`
- `θ` → `夹角 theta`
- `½at²` → `二分之一 a t 平方`
- `m/s²` → `米每二次方秒`
- `m/s` → `米每秒`
- `v-t 图` / `x-t 图` → `v t 图像` / `x t 图像`

## 2. 中文物理多音字消歧（按需替换为同音或停顿词）
- “弹力 / 弹性” → 保持正常语境，避免孤立单字“弹”
- “重合 / 重力” → “重力”直接读，“重合”注意上下文
- “处（chù）于静止” → 可写“处于静止状态”帮助断句
- “长（cháng）度 / 板长” → 明确写成“木板长度”或“最小板长”

## 3. 3Blue1Brown 节奏建议
- 每句讲稿控制在 **12～28 个汉字**，对应 **2.5～6 秒** 动画节拍；
- 关键转折（如“注意，这里就是共速临界点！”）前后留 `0.3s` 停顿，配合画布高亮动画。
